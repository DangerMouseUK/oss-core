# Reference vectors

Data files produced by running unmodified reference implementations (ASSS 1.4.4 modules compiled as-is, and nullspace's MIT checksum routine) on synthetic or public-default inputs. They are inputs and outputs only, no code. Each file's header lines (`#`) describe its record format.

- `vie.txt`: VIE key exchange, 520-byte tables, per-packet encrypt/decrypt for 16 keys (including edge keys) and 48 packets each.

This project's own protocol is checked differently:

- `opensec.txt` holds the OpenSec v1 vectors (`docs/protocol/opensec.md`, section 9). They are generated by `oss-net`'s `published_vectors` test, and include complete handshakes with every intermediate value, records, rejected hellos and replay-window sequences.
- `opensec_check.py` re-derives all of them independently: standard-library Python, written from the spec, with its own X25519, ChaCha20-Poly1305 and HKDF. Run `python3 opensec_check.py`.
