# Conformance vectors

Inputs and expected outputs only, no code. Each `.txt` file's `#` header describes its records. The suite embeds these files; `tests/suite.rs` checks that they match the copies the other crates are tested with.

| File | Source |
|---|---|
| `vie.txt`, `position-checksum.txt`, `clientset-*.txt`, `map-checksum-*.txt` | produced by running unmodified ASSS 1.4.4 server modules on synthetic or public-default inputs |
| `vie-exe-checksum.txt` | nullspace's MIT checksum routine |
| `opensec.txt` | this project's OpenSec implementation (`oss-net`), from the spec in `docs/protocol/opensec.md` |
| `packets.txt` | canonical encodings, generated by `oss-proto/tests/roundtrip.rs` (`OSS_REGEN_VECTORS=1`) |
| `relay.txt` | WebSocket relay frames from `docs/protocol/websocket-relay.md` |
| `smallmap.lvl` | ASSS's default sample map (GPL sample data) |
| `synth-*.lvl` | seeded synthetic maps, generated by `oss-formats/tests/synthetic_maps.rs` (`OSS_REGEN_VECTORS=1`) |
