## Layout

| Offset | Size | Type | Field | Meaning |
|---|---|---|---|---|
| 0 | 1 | u8 | type | `0x39` |
| 1 + 10i | 1 | u8 | pid |  |
| 2 + 10i | 2 | u16 | rotation, time | Rotation in bits 10–15, low 10 bits of the time in 0–9 |
| 4 + 10i | 4 | u32 | x, y, x speed | x in bits 0–13, y in 14–27, x-speed bits 0–3 in 28–31 |
| 8 + 10i | 2 | u16 | y speed, x speed | Signed 14-bit y speed in bits 0–13, x-speed bits 4–5 in 14–15 |
| 10 + 10i | 1 | i8 | x speed | x-speed bits 6–13 (carries the sign) |

Integers are little-endian. `n` is a variable length; `i` counts repeated entries from 0.

## Notes

Only for clients that advertise batched positions.
