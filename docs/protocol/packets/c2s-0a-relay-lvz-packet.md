## Layout

| Offset | Size | Type | Field | Meaning |
|---|---|---|---|---|
| 0 | 1 | u8 | type | `0x0A` |
| 1 | 2 | i16 | target | −1 = the arena |
| 3 | n | bytes | packet | An S2C `0x35` or `0x36` packet, at least one byte |

Integers are little-endian. `n` is a variable length; `i` counts repeated entries from 0.

## Notes

A 3-byte packet (no inner packet) is invalid; `Rebroadcast::new` refuses it.
