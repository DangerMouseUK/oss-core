## Layout

| Offset | Size | Type | Field | Meaning |
|---|---|---|---|---|
| 0 | 1 | u8 | type | `0x06` |
| 1 | 4 | u32 | connection_id |  |
| 5 | 4 | u32 | server_id | The zone that should receive it, by the server id in its ServerConnect |
| 9 | 1 | u8 | kind | `0x01` permit; anything else a message |
| 10 | 1 | u8 | sound | Message only |
| 11 | n | char[] | text | Message only; NUL-terminated |
| 10 | n | char[] | name | Permit only: the player to permit; NUL-terminated |

Integers are little-endian. `n` is a variable length; `i` counts repeated entries from 0.

## Notes

Kind `0x01` asks the biller to send a permit entry (B2S `0x03` kind `0x01`) to the zone with that server id. It has no sound byte, and the biller sends no reply. The billing protocol write-up documents only the message form.
