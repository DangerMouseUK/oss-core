## Layout

| Offset | Size | Type | Field | Meaning |
|---|---|---|---|---|
| 0 | 1 | u8 | type | `0x2F` |
| 1 | n | char[] | name | NUL-terminated; repeated with the population |
| … | 2 | i16 | population | Negative for the arena you are in |

Integers are little-endian. `n` is a variable length; `i` counts repeated entries from 0.
