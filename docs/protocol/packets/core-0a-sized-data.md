## Layout

| Offset | Size | Type | Field | Meaning |
|---|---|---|---|---|
| 0 | 1 | u8 | core | `0x00` |
| 1 | 1 | u8 | subtype | `0x0A` |
| 2 | 4 | i32 | total | Size of the whole transfer |
| 6 | n | bytes | slice |  |

Integers are little-endian. `n` is a variable length; `i` counts repeated entries from 0.

## Notes

Always inside a reliable. Used for map and LVZ downloads.
