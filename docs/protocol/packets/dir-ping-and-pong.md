## Layout

| Offset | Size | Type | Field | Meaning |
|---|---|---|---|---|
| 0 | 4 | u32 | value | Ping: any value, echoed |
| 0 | 4 | u32 | info | Pong: informational (zone count in one directory) |
| 4 | 4 | u32 | value | Pong: the ping's value |

Integers are little-endian. `n` is a variable length; `i` counts repeated entries from 0.
