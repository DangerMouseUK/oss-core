## Layout

| Offset | Size | Type | Field | Meaning |
|---|---|---|---|---|
| 0 | 1 | u8 | type | `0x03`, repeated at the start of every record |
| 1 | 1 | i8 | ship | 0–7, 8 = spectator |
| 2 | 1 | u8 | accept_audio | Accepts voice messages. |
| 3 | 20 | char[20] | name | NUL-padded; may lack a NUL |
| 23 | 20 | char[20] | squad | NUL-padded; may lack a NUL |
| 43 | 4 | i32 | kill_points |  |
| 47 | 4 | i32 | flag_points |  |
| 51 | 2 | i16 | pid |  |
| 53 | 2 | i16 | freq |  |
| 55 | 2 | i16 | wins |  |
| 57 | 2 | i16 | losses |  |
| 59 | 2 | i16 | attached_to | Turret host, −1 none |
| 61 | 2 | i16 | flags_carried |  |
| 63 | 1 | u8 | misc | Bit 0 has a crown, bit 1 send damage reports for this player |

Integers are little-endian. `n` is a variable length; `i` counts repeated entries from 0.

## Notes

Several 64-byte records may be concatenated; each starts with its own `0x03`. Offsets are within one record.
