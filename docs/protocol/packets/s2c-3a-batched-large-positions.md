## Layout

| Offset | Size | Type | Field | Meaning |
|---|---|---|---|---|
| 0 | 1 | u8 | type | `0x3A` |
| 1 + 11i | 2 | u16 | pid, status | pid in bits 0–9, status bits 0–5 in 10–15 |
| 3 + 11i | 2 | u16 | rotation, time | As in `0x39` |
| 5 + 11i | 4 | u32 | x, y, x speed | As in `0x39` |
| 9 + 11i | 2 | u16 | y speed, x speed | As in `0x39` |
| 11 + 11i | 1 | i8 | x speed | As in `0x39` |

Integers are little-endian. `n` is a variable length; `i` counts repeated entries from 0.

## Notes

Only for clients that advertise batched positions.
