## Layout

| Offset | Size | Type | Field | Meaning |
|---|---|---|---|---|
| 0 | 1 | u8 | type | `0x2A` |
| 1 | 16 | char[16] | name |  |
| 17 | n | bytes | data | Maps zlib-compressed; LVZ files as stored |

Integers are little-endian. `n` is a variable length; `i` counts repeated entries from 0.

## Notes

Larger than a datagram, so it travels as big or sized data. The conformance suite downloads and checks the map in its live server checks.
