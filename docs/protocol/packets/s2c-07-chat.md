## Layout

| Offset | Size | Type | Field | Meaning |
|---|---|---|---|---|
| 0 | 1 | u8 | type | `0x07` |
| 1 | 1 | u8 | kind | Chat type (0 arena … 9 channel) |
| 2 | 1 | u8 | sound | 0 = none |
| 3 | 2 | i16 | pid | Sender, −1 none |
| 5 | n | char[] | text | NUL-terminated |

Integers are little-endian. `n` is a variable length; `i` counts repeated entries from 0.

## Notes

Remote private messages arrive as `(name)>text` with pid −1; channel messages as `n;text`. Chat types are listed in [game-packets.md](../game-packets.md#chat-types).
