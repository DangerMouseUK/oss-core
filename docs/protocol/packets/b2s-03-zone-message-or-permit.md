## Layout

| Offset | Size | Type | Field | Meaning |
|---|---|---|---|---|
| 0 | 1 | u8 | type | `0x03` |
| 1 | 4 | u32 | source_server |  |
| 5 | 1 | u8 | kind | `0x02` message; `0x01` permit entry |
| 6 | 1 | u8 | sound | Message only |
| 7 | n | char[] | text | Message only: `:target:(from)>msg` is a remote private message; NUL-terminated |
| 6 | n | char[] | name | Permit only: a name to add to this zone's permit list; NUL-terminated |

Integers are little-endian. `n` is a variable length; `i` counts repeated entries from 0.

## Notes

Kind `0x01` is a permit entry, which the biller routes here from another zone's S2B `0x06`. It has no sound byte, so check the kind before reading offset 6. The zone conventionally appends the name to `permit.txt`; there is no reply and no way to revoke it. The reference server acts only on kind `0x02`.
