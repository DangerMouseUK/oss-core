## Layout

| Offset | Size | Type | Field | Meaning |
|---|---|---|---|---|
| 0 | 1 | u8 | type | `0x29` |
| 1 | 16 | char[16] | name | 21-byte form: the map |
| 17 | 4 | u32 | checksum | 21-byte form: CRC-32 of the uncompressed map |
| 1 + 24i | 16 | char[16] | name | Long form: entry 0 is the map, the rest LVZ files |
| 17 + 24i | 4 | u32 | checksum | Long form: CRC-32 of the file as stored |
| 21 + 24i | 4 | u32 | size | Long form: total length of the `0x2A` packet that carries it |

Integers are little-endian. `n` is a variable length; `i` counts repeated entries from 0.

## Notes

The client requests entry *i* with C2S `0x0C`. Clients without LVZ support get the 21-byte form.
