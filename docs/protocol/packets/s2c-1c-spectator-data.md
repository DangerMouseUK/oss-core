## Layout

| Offset | Size | Type | Field | Meaning |
|---|---|---|---|---|
| 0 | 1 | u8 | type | `0x1C` |
| 1 | 1 | u8 | extra_data | 2-byte form: 1 = append extra position data to your positions |
| 1 | 2 | i16 | pid | 3-byte form: this player became a spectator of you |

Integers are little-endian. `n` is a variable length; `i` counts repeated entries from 0.

## Notes

The length selects the form. Continuum accepts only the 2-byte form, and no known server sends the 3-byte one (per the QS protocol reference (poid.be/subspace/protocols)); oss-core decodes it, but nothing should send it.
