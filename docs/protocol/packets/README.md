# Packet reference

Licence: [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Generated by `oss-proto/tests/protocol_pages.rs`.

One page per packet that oss-core implements, with its byte layout and the evidence behind it. Fixed-layout game packets are rendered from the codec's own field metadata (`FIELDS`). Evidence levels:

- **Vectors**: checked byte for byte against an unmodified reference implementation;
- **Sources**: agrees with the reference server and at least one other source;
- **Partly inferred**: some fields' meaning is unknown (named on the page).

See [verification.md](../verification.md). This project's own protocols have their own specifications: [opensec.md](../opensec.md) and [websocket-relay.md](../websocket-relay.md).

135 pages: 23 vectors, 100 sources, 12 partly inferred.
